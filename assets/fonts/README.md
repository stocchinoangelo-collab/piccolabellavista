# Font locali

Famiglie preesistenti nel sito: Fraunces (400, 500, 600), Inter (400, 600, 700, 800).
File acquisiti il 9 settembre 2026 da Google Fonts / fonts.gstatic.com senza alterazione del font.
OFL originale: https://github.com/google/fonts/tree/main/ofl/fraunces e https://github.com/google/fonts/tree/main/ofl/inter.
`fonts.css` associa i sette file originali alle famiglie e ai pesi corrispondenti.
Questa copia locale evita richieste a Google Fonts durante la visita al sito.
